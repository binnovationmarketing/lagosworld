# BUSINESS TEMPLATE — Framework de Negócio Lagos World

> Framework estratégico e comercial extraído do projeto Lagos World.
> Use como base para qualquer novo site de negócio.

---

## 1. ESTRUTURA DE POSICIONAMENTO

### Fórmula de posicionamento
```
[MARCA] é para [PÚBLICO] que quer [DESEJO],
sem [OBSTÁCULO], através de [MECANISMO ÚNICO].
```

**Exemplo Lagos Jewelry**:
> Lagos Jewelry é para mulheres latinas em Filadélfia que querem se sentir elegantes no dia a dia, sem gastar muito, através de joias 18k selecionadas com propósito.

**Exemplo Lagos Cleaning**:
> Lagos Cleaning é para proprietários de imóveis em PA e NJ que querem uma limpeza profissional confiável, sem surpresas, com resposta em 2 horas e satisfação garantida.

### Elementos de posicionamento obrigatórios
1. **Nicho específico** — não "todo mundo", mas "mulheres 25–55 em Filadélfia"
2. **Fundador/a visível** — quem está por trás, não uma empresa anônima
3. **Propósito** — além do produto/serviço, qual é o "porquê"
4. **Diferencial defensável** — algo que você faz diferente e pode provar
5. **Prova** — número, review, depoimento ou resultado real

## 2. ESTRUTURA DE OFERTA

### Modelo de oferta por camada (Lagos pattern)
```
Camada 0 — Lead Magnet:     Newsletter / Free Quote / Desconto Boas-vindas
Camada 1 — Produto Entrada: Item de menor preço / Serviço inicial
Camada 2 — Produto Core:    Produto/serviço principal
Camada 3 — Upsell:          Cross-sell / pacote completo / recorrência
Camada 4 — VIP:             Experiência premium / lista exclusiva / acesso antecipado
```

**Jewelry**:
```
0: Newsletter → WELCOME10 (10% off)
1: Brincos simples ($18–$25)
2: Colar/Pulseira ($35–$65)
3: Kit coordenado ($75–$120)
4: VIP List → early access
```

**Cleaning**:
```
0: Free Quote / 15% primeiro serviço
1: One-time house cleaning
2: Recurring weekly/biweekly
3: Deep clean + pressure wash combo
4: Referral program (desconto para ambos)
```

### Regra de precificação de tela
- Mostre o preço APENAS se ele não for uma objeção (produtos baratos — sim, serviços caros — cotação)
- Para serviços de ticket alto: substitua preço por "Get Free Quote" → converte melhor
- Âncora de valor: sempre que mostrar preço, context é "qual o valor de ter isso?"

## 3. ESTRUTURA DA PÁGINA INICIAL

### Sequência universal provada no projeto
```
1. TOP BAR        → Urgência / Número / Promoção flash
2. NAV            → Marca | Links | CTA Principal
3. HERO           → Impacto + proposta de valor + CTA
4. TRUST STRIP    → 4 badges de confiança (rápido, sem ler)
5. SERVICES       → O que você oferece (com destaque para o mais vendido)
6. HOW IT WORKS   → Processo em 3–4 passos (reduz fricção)
7. PROOF          → Before/After ou Fotos reais do trabalho
8. REVIEWS        → 3–6 depoimentos com nome + data
9. PROMO SECTION  → Oferta especial (urgência controlada)
10. FAQ           → Responde objeções comuns
11. FINAL CTA     → Repetição do formulário/botão principal
12. FOOTER        → Links + Contato + Copyright
```

### Por que essa sequência funciona
- Items 1–3: capturam atenção (visita não sai)
- Items 4–5: qualificam o visitante ("isso é pra mim?")
- Items 6–8: constroem confiança ("funciona de verdade?")
- Items 9–10: superam objeções ("mas e se...?")
- Items 11–12: convertem quem estava apenas "pensando"

## 7. ESTRUTURA DE FUNIL

### Funil completo Lagos Pattern
```
TOPO (Awareness)
├── Google Search (SEO local)
├── WhatsApp link
├── Instagram bio
└── Referral (boca a boca)

MEIO (Consideration)
├── Landing page (hero + serviços + reviews)
├── Newsletter popup (captura email)
├── WhatsApp float (tire dúvidas)
└── Before/After + FAQ (reduz objeções)

FUNDO (Conversion)
├── Formulário de agendamento / Checkout
├── Email de confirmação automático
└── WhatsApp follow-up (pessoal)

PÓS-CONVERSÃO (Retention)
├── Email sequence automatizado (4–5 emails)
├── Review request (+30d)
└── Referral program (+45d)
```

### KPIs para medir cada etapa
```
Topo:     Visitas únicas / mês
Meio:     Taxa de captura de email (newsletter)
Fundo:    Taxa de conversão formulário / checkout
Retenção: % clientes que voltam / % que indicam
```

## 8. ESTRUTURA DE COPYWRITING

### Fórmula AIDA adaptada (usada no projeto)
```
A — ATENÇÃO:   Visual antes de texto (foto/gradiente/animação)
I — INTERESSE: "Para mulheres que..." / "Se você precisa de..."
D — DESEJO:    Benefício emocional + prova social
A — AÇÃO:      CTA específico + urgência opcional
```

### Fórmula de headline
```
[RESULTADO DESEJADO] + [PRAZO OU FACILIDADE] + [PARA QUEM]

Exemplos:
"Your home clean and fresh in 4 hours — guaranteed"
"Feel elegant every day without spending a fortune"
"Launch your online course in 30 days — step by step"
```

### Regras de copy (extraídas do projeto)
1. **Benefit first** — "Feel beautiful" antes de "18k gold plated"
2. **Específico vence genérico** — "4h response" vence "fast response"
3. **Social proof numérico** — "87 reviews" mais forte que "many reviews"
4. **Micro-copy importa** — "Powered by trust" no formulário reduz ansiedade
5. **Versículo/propósito** — humaniza e cria conexão com o público certo
6. **Founder story** — "Dayane começou porque..." converte mais que "nós somos"

### Sequência de email (copy framework)
```
Email 1 (Welcome):      VOCÊ + propósito + o que esperar
Email 2 (Value):        Conteúdo útil / dica / história
Email 3 (Social Proof): Depoimento de cliente + "você merece isso"
Email 4 (Offer):        Oferta específica com urgência
Email 5 (Follow-up):    Última chance / diferente ângulo
```

## 9. ESTRUTURA DE SEO

### Schema.org por tipo de negócio
```
Limpeza local:     "@type": "CleaningService"
Joalheria:         "@type": "JewelryStore"
Restaurante:       "@type": "Restaurant"
Consultoria:       "@type": "ProfessionalService"
Curso online:      "@type": "Course"
E-commerce:        "@type": "Product" (por produto)
```

### Campos obrigatórios no Schema LocalBusiness
```json
{
  "name": "Nome do Negócio",
  "telephone": "+1XXXXXXXXXX",
  "address": { "addressLocality": "City", "addressRegion": "STATE" },
  "geo": { "latitude": X.XXXX, "longitude": -XX.XXXX },
  "aggregateRating": { "ratingValue": "4.9", "reviewCount": "87" }
}
```

### Checklist de SEO por página
```
[ ] <title> = Keyword principal + Localização + Marca (60 chars max)
[ ] <meta description> = Benefício + CTA + Localização (155 chars max)
[ ] <h1> = Uma por página, contém keyword principal
[ ] <h2> = Estrutura de subseções com variações da keyword
[ ] <alt> = Descreve imagem com keyword contextual
[ ] Canonical = URL definitiva sem parâmetros
[ ] Open Graph = Imagem 1200×630, título, descrição
[ ] Schema.org = Tipo correto com todos os campos
[ ] Speed = Imagens lazy loaded, Google Fonts preconnect
```

## 10. ESTRUTURA DE CTA

### Hierarquia de CTAs por página
```
Nível 1 (Principal): 1 botão grande no hero — ação mais importante
Nível 2 (Secundário): 1–2 botões de suporte (WhatsApp, "Learn More")
Nível 3 (Float): WhatsApp sempre visível no canto inferior direito
Nível 4 (Inline): CTAs dentro das seções ("Book this service")
Nível 5 (Email): CTA no final de cada email enviado
```

### Cores de CTA por intenção
```
Comprar/Pagar:      Cor primária cheia (gold, teal, etc.)
Agendar/Cotar:      Cor primária filled
WhatsApp:           Verde WhatsApp #25D366
Secundário:         Outline (border + texto da cor primária)
Perigo/Cancelar:    Vermelho ou cinza
```

## 11. ESTRUTURA DE CONFIANÇA

### Pirâmide de confiança (base → topo)
```
TOPO ← Garantia explícita ("money-back / free redo")
        Depoimentos com foto e nome real
        Before/After com resultados reais
        Certificações e seguros (Bonded & Insured)
        Número de clientes servidos
BASE ← Visual profissional (site bem feito = empresa séria)
```

### Como implementar cada nível
```
Visual profissional:  Cores consistentes, fontes legíveis, sem typos
Fundador visível:     Foto real + nome + título (não "nossa equipe")
Prova numérica:       "500+ homes cleaned" / "87 reviews / 4.9★"
Certificação:         Badge de garantia no hero + footer
Depoimentos:          Nome + cidade + data + rating + foto (se possível)
Garantia:             "Se não gostar, fazemos de novo — grátis"
```

## 12. ESTRUTURA DE MARCA

### Sistema de marca por negócio (Lagos Pattern)
```
Nome da marca:     Uma palavra + qualificador OU nome pessoal
                   Exemplos: Lagos Jewelry / Lagos Cleaning / "By Dayane"

Sub-marca:         Diferencia cada vertical sem perder identidade
                   Lagos [Vertical] → funciona como guarda-chuva

Tom de voz:
  Jewelry:         Elegante, aspiracional, com propósito, feminino
  Cleaning:        Profissional, direto, confiável, próximo
  Regra geral:     Escreva como se fosse a fundadora falando

Paleta de marca:   1 cor primária + 3 variações + neutros
                   Não use mais de 3 cores visíveis por página

Tipografia:        1 serif (display/hero) + 1 sans-serif (corpo)
                   Nunca mais de 2 famílias por página
```

## 13. ESTRUTURA PARA ESCALAR PARA OUTROS NICHOS

### Checklist de scaling
```
[ ] O público é specific enough? (não "mulheres" mas "mulheres latinas 30–50 em Philly")
[ ] Existe demanda local/online verificável? (Google Keyword Planner)
[ ] O fundador/a tem credibilidade ou história nesse nicho?
[ ] O site consegue capturar lead antes da conversão? (newsletter/form)
[ ] Existe sequência de email para nurturar esse lead?
[ ] Existe diferencial defensável vs. concorrentes?
[ ] O ticket médio justifica o custo de aquisição?
```

### Ordem de prioridade ao criar novo vertical
```
1. Validar demanda (Google Trends, grupos, WhatsApp)
2. Criar landing page simples (hero + serviço + formulário + email)
3. Configurar email automático de confirmação
4. Testar com 5–10 primeiros clientes (manual)
5. Escalar: adicionar reviews, expandir SEO, criar sequência de email
6. Só então: refinar visual, adicionar features complexas
```
